# Customer Shopping Behavior Analysis

## 📊 Project Overview

This project analyzes customer shopping behavior using Python, SQL, and Power BI.

The objective is to identify customer purchasing patterns, revenue trends, product performance, demographic insights, subscription behavior, discount effectiveness, and payment preferences.

* Pandas
* SQL

## 🐍 Python Analysis

Python and Pandas were used for data preprocessing and feature engineering.

Key activities included:

* Handling missing values
* Converting review ratings to numeric values
* Standardizing column names
* Renaming columns
* Creating customer age groups
* Converting purchase frequency into purchase-frequency days
* Preparing the dataset for further analysis

## 🗄️ SQL Analysis

SQL was used to analyze customer purchasing behavior and business performance.

Key analyses included:

* Total revenue
* Average purchase amount
* Minimum and maximum purchase amount
* Revenue by product category
* Top 10 products by revenue
* Revenue by age group
* Top locations by revenue
* Revenue comparison by gender
* Revenue by season
* Subscription vs non-subscription customers
* Discount vs non-discount customers
* Promo code effectiveness
* Payment method analysis

## 📊 Power BI Dashboard

## 💡 Key Business Questions

The project answers questions such as:

1. What is the total revenue generated?
2. Which product categories generate the highest revenue?
3. Which products generate the most revenue?
4. Which age group contributes the highest revenue?
5. Which locations generate the highest revenue?
6. How do male and female customers compare?
7. Which season generates the highest revenue?
8. Do subscribed customers generate more revenue?
9. Are discounts associated with higher average purchase amounts?
10. How effective are promo codes?
11. Which payment methods are most commonly used?
